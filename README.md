In this first installment, a comprehensive dataset encompassing various types of mushrooms found worldwide is analyzed. The project repository consists of three files: a Jupyter Notebook containing the developed visualizations, a CSV file with the dataset, and a Word document providing a detailed description of the database, along with a brief analysis and project conclusion.

The analysis classifies mushrooms into two primary categories: edible and non-edible. A comparative evaluation is conducted based on the presence or absence of rings, population grouping patterns, and natural habitats. Further analysis includes stem types and colors, as well as cap types, colors, and shapes. Additionally, the study examines the presence of odors and analyzes gill characteristics, veil types, and spore colors to identify distinguishing features between the two categories.
